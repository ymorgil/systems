# **📋 UT01 · Rúbrica de evaluación**

Rúbrica de comprobación del reto *Diagnóstico y plan digital de una empresa real*. Para cada uno de los 10 apartados obligatorios se comprueban **4 elementos**: cada elemento se marca como presente (Sí) o ausente (No). No hay términos medios: o la evidencia está en la entrega, o no lo está. Esta misma rúbrica es la que se usará en la **evaluación entre iguales** del taller de Moodle antes de la calificación del profesorado.

### Apartado 1 · Selección de la empresa y gran idea del grupo

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | Se ha elegido una empresa concreta (real o ficticia verosímil) de un sector productivo | | |
| 2 | La ficha incluye sector, tamaño aproximado, actividad y ámbito geográfico | | |
| 3 | Se justifica por qué el grupo ha elegido esa empresa | | |
| 4 | Se formula una pregunta esencial de grupo coherente con la empresa elegida | | |

### Apartado 2 · Análisis de la situación digital actual

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | Se describen las herramientas digitales que ya usa la empresa | | |
| 2 | Se identifican procesos que siguen siendo manuales o en papel | | |
| 3 | Se distingue entre digitalización puntual y posible transformación digital | | |
| 4 | El análisis se apoya en ejemplos concretos de la empresa, no en generalidades | | |

### Apartado 3 · Identificación de los entornos IT del negocio

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | Se identifican los datos de negocio que gestiona o debería gestionar la empresa | | |
| 2 | Se proponen sistemas de información concretos (ERP, TPV, agenda digital...) | | |
| 3 | Se relacionan funciones o departamentos IT del temario con la realidad del negocio | | |
| 4 | Cada elemento IT se justifica con un ejemplo concreto de la empresa elegida | | |

### Apartado 4 · Identificación de los entornos OT del negocio

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | Se identifican máquinas, sensores o procesos físicos propios del negocio | | |
| 2 | Los elementos OT descritos son coherentes con el sector de la empresa | | |
| 3 | Si no existe entorno OT, se justifica razonadamente su ausencia | | |
| 4 | Se diferencia con claridad el entorno OT del entorno IT ya descrito | | |

### Apartado 5 · Análisis de la convergencia IT/OT en el negocio elegido

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | Se propone al menos un ejemplo realista de conexión entre datos OT y decisiones IT | | |
| 2 | El ejemplo está adaptado a la empresa elegida y no es genérico | | |
| 3 | Se mencionan riesgos u oportunidades derivados de esa convergencia | | |
| 4 | Si no hay entorno OT, se razona sobre oportunidades/riesgos de una futura convergencia | | |

### Apartado 6 · Diagnóstico digital de la empresa

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | El diagnóstico resume con claridad qué está digitalizado y qué no | | |
| 2 | Se identifican riesgos u oportunidades concretas de la empresa | | |
| 3 | Se plantea un problema concreto que justifica el proyecto de digitalización | | |
| 4 | El diagnóstico describe la situación sin adelantar ya la solución | | |

### Apartado 7 · Definición de los objetivos del Plan Digital

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | Se formulan entre 2 y 4 objetivos para el Plan Digital | | |
| 2 | Los objetivos son concretos y medibles, no genéricos | | |
| 3 | Cada objetivo indica un indicador para comprobar su cumplimiento | | |
| 4 | Los objetivos son coherentes con el diagnóstico y la pregunta esencial de grupo | | |

### Apartado 8 · Elección de tecnologías del Plan Digital

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | Se elige al menos una tecnología concreta por cada objetivo definido | | |
| 2 | Cada tecnología se justifica en relación con el objetivo, no por moda | | |
| 3 | Se distingue, cuando procede, entre tecnología de planta (OT) y de negocio (IT) | | |
| 4 | Las tecnologías elegidas son coherentes con el diagnóstico del apartado 6 | | |

### Apartado 9 · Plan de gestión del cambio y ciberseguridad

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | Se identifica la resistencia al cambio esperable y cómo abordarla | | |
| 2 | Se describe la formación necesaria para la plantilla | | |
| 3 | Se proponen medidas mínimas de ciberseguridad y protección de datos (RGPD) | | |
| 4 | Se relaciona el apartado con las responsabilidades de dirección del temario | | |

### Apartado 10 · Documentación final y publicación en el taller de Moodle

| # | Elemento a comprobar | Sí | No |
|---|---|---|---|
| 1 | El documento final integra de forma coherente los apartados 1 a 9 | | |
| 2 | Incluye un esquema o diagrama de los entornos IT/OT y su conexión | | |
| 3 | El documento se ha subido al taller de Moodle dentro del plazo de entrega | | |
| 4 | El grupo ha completado la evaluación entre iguales de, al menos, dos trabajos compañeros | | |

## Calificación

Cada elemento marcado "Sí" suma un punto (máximo 40 puntos). La calificación sobre 10 se obtiene dividiendo el total entre 4. Para superar la unidad es necesario alcanzar al menos 20 de los 40 elementos y tener, como mínimo, 2 de los 4 elementos marcados en cada uno de los 10 apartados (ningún apartado puede quedar completamente vacío).
